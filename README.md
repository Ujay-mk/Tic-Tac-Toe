# Tic-Tac-Toe
The Worst Tic-Tac-Toe Game Ever Made.
🐍 TicTacToe (But Bad) – Made with Ursina
Welcome to the worst best TicTacToe game you've probably never asked for!
This is a glorified 3x3 button mash made with the Ursina game engine, complete with:

Glitches

No win detection (sometimes)

Player confusion

Questionable UI

Yes, it’s TicTacToe. No, it’s not good.

⚠️ Features (if you can call them that)
 Players take turns… mostly.

 Xs and Os show up (yay!).

 Win condition detection (works when it wants to).


🛠 How to Run
Make sure you have Python and Ursina installed, then run:
python ttt.py

If it crashes... well, that's part of the experience.

🎮 Controls
Left Click to place your X or O.


😵 Known "Features"
No restart button. You lose? Just close and reopen.

Game might forget whose turn it is.


🤡 Why Does This Exist?
I was learning Ursina. Then I stopped trying.
This game is the result. Enjoy!
